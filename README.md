# АДБ Проект-5 — демо сайта архитектурного бюро

Два концептуально разных варианта лендинга для ООО «АДБ Проект-5» и интерактивный изометрический макет дома: его можно вращать мышью и раскладывать на слои.

> Демо: проекты, тексты и форма — заглушки. Реальных фактов о компании на сайте нет.

| Страница | Что внутри |
|---|---|
| [`index.html`](index.html) | Выбор варианта |
| [`variant-a.html`](variant-a.html) — **«Монолит»** (тёмный по умолчанию) | Полноэкранный raymarch-шейдер: бетонный зал, туман и лучи света через щель в стене, свет идёт за курсором. Манифест, проявляющийся при прокрутке; sticky-секция, где прокрутка разбирает дом по слоям; каскад карточек проектов; линия этапов, которая рисуется при прокрутке. |
| [`variant-b.html`](variant-b.html) — **«Чертёж»** (светлый по умолчанию) | Интерактивный WebGL-градиент на миллиметровке: линза и циркуль под курсором, волны по клику, штамп листа с координатами. Макет дома с выносками слоёв и размерами, горизонтальный альбом проектов, 3D-карусель услуг, счётчики. |
| [`house/house.html`](house/house.html) | Макет дома отдельно, на весь экран |

В обоих вариантах есть переключатель тёмной и светлой темы (сохраняется в `localStorage`, можно задать `?theme=light|dark`).

## Макет дома

Двухэтажный частный дом на круглом подиуме построен на 3D-режиме кита [Anatomy](https://github.com/wheresryan22/anatomy) (MIT, копия в [`kit/`](kit)). Каждый кадр детали заново проецируются и затеняются, порядок отрисовки решается через разделяющие плоскости.

- **Слои:** фундаментная плита и терраса → 1 этаж (стены, лестница, кухня) → перекрытие с контуром тёплого пола → 2 этаж в деревянной облицовке с консолью → двускатная кровля с солнечными панелями.
- **Управление:** перетаскивание мышью или пальцем вращает дом с инерцией; `←`/`→` поворачивают, `↑`/`↓` разбирают, `Home` сбрасывает. Слайдер «Разрез».
- **Цифры** (площадь, толщины, уклон) берутся из одного файла — [`house/model.mjs`](house/model.mjs). Сайт импортирует его напрямую.
- **API для встраивания:** родительская страница отправляет `postMessage({ type: "hx:set", explode, yaw, theme, tour })` и получает `hx:state`. Параметры URL: `ui=0`, `theme`, `tour=0`, `yaw`, `explode`.

## Запуск

```sh
node server.mjs          # http://127.0.0.1:4190, PORT меняет порт
```

Зависимостей и сборки нет. Шрифты подключаются из Google Fonts (без сети используются системные).

## Пересборка макета

```sh
node house/build.mjs                    # пишет house/house.html (около 0,3 с)
node house/build.mjs --audit --quick    # аудит геометрии кита и быстрый орбитальный аудит
node house/build.mjs --audit            # полный орбитальный аудит (долго)
```

## Проверки

```sh
node --test tests/site.test.mjs                         # структура, ссылки, модель, сервер
node tests/browser.mjs                                  # Chrome + запущенный сервер: 1440 и 390 px, темы, drag, разрез, overflow, без WebGL
node tests/viewport-shots.mjs http://127.0.0.1:4190/variant-a.html a   # скриншоты в shots/
```
